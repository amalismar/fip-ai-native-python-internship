### Functions, Modules, Clean Code

## Project: Utility Package (Tool Kit)

This package demonstrates reusable functions, parameters, and return values, docstrings, standard-library imports, and modular code organisation

# Project Features
 - Calculator
 1. Addition
 2. Subtraction
 3. Multiplication
 4. Division

 - Age Calculator
 1. Calculate age
 2. Accepts year, month, and day of birth

 - Password Toolkit
 1. Basic check for password strength
 2. Random password generator
 3. Password length validation

# Concepts Demonstrated
- Defining reusable functions
- Using parameters and return values
- Writing docstrings
- Importing functions from modules
- Organising a Python package
- Using the standard library
- Handling invalid operations
- Following basic PEP 8 conventions
