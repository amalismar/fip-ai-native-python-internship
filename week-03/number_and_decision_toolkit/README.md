# PROJECT 1: Number and Decision Toolkit
This TOOklit is a CLI application that can be used to carry out three different operations. It consists of a calculator, a unit converter and a decisions checker all in one interactive program.

It displays an understanding of control flow, loops, comparisons in programming to solve a bounded programming problem.

Features
1. Navigating the Menu
This feature allows users to go through each option until they select exit and dispalys an error for any invalid choice selected

2. A Calculator
The calculator carries out Addition, Subtraction, Multiplication and Division. This tools also carries out invaid-input handling

3. Unit Converter
This tool converts in length (meters to feet), weight (kilograms to pounds) and temeprature (celcius to farenheit). It also handles invalid inputs

4. Decision Checker
This checks if the number inputed by the user is odd or even, positive, negative, or a zero number, as well as if it is greater than 10. 

# How to Run this Project
1. Install Python
2. Open the project in Visual Studio Code
3. Open the terminal to the number_and_decision_toolkit directory
4. Run the command: python toolkit.py
5. Select an option to begin
